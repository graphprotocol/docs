## Indexing Data on Elysium

Elysium is a high-throughput Arbitrum Orbit Layer 2 built by Kinetiq for the Hyperliquid ecosystem. It settles to HyperEVM, uses HYPE as its gas token, and targets 100–200 ms blocks for spot trading, market making, token launches, and DeFi apps. The Graph can stream that onchain activity — DEX swaps, pools, and liquidity; lending and borrowing positions; token transfers and holder balances; and contract events — as real-time data with Substreams.

Elysium is supported by The Graph with Substreams — a parallelized, real-time streaming engine for high-throughput use cases — via [The Graph Market](https://thegraph.market/).
