## Indexing Data on X Layer

X Layer is an Ethereum Layer 2 zkEVM built by OKX on the Polygon CDK, connecting the OKX ecosystem to onchain DeFi, with OKB as its gas token. The Graph can index that onchain activity, including DEX swaps, pools, and liquidity; lending and borrowing positions; token transfers and holder balances; and contract events. That powers DeFi frontends, analytics dashboards, block explorers, portfolio trackers, and onchain agents without teams having to run their own indexing infrastructure.

X Layer is supported by The Graph in two ways:

- **[Subgraphs](/subgraphs/developing/deploying-publishing/using-subgraph-studio/)**: The blockchain indexing standard perfect for small to medium-sized projects that need hosted APIs. Data consumers develop, publish, and query their Subgraphs in [Subgraph Studio](/subgraphs/providers/subgraph-studio/introduction/), though guaranteed indexing via The Graph Network is not yet available for X Layer.
- **[Substreams](/substreams/quick-start/)**: A real-time streaming engine for transaction-heavy projects, high-throughput chains, and institutions that need custom data infrastructure. Data consumers can manage their service and get indexing via [Pinax Network](https://app.pinax.network/docs?from=nav).
