A Gateway Operator runs a gateway that serves queries for Subgraphs published to The Graph Network. Multiple Gateway Operators serve the network. Published Subgraphs live onchain, so every gateway can serve every published Subgraph, and you can change gateways without republishing.

## What a Gateway Operator Does

When your application sends a query, the gateway:

1. Checks your API key or other credentials.
2. Selects Indexers on The Graph Network that serve the Subgraph, and routes the query to them.
3. Pays those Indexers in GRT through [GraphTally](/gateways/subgraphs/components/graph-tally/).
4. Returns the response, and bills you on the terms it sets.

Some Gateway Operators also offer tools beyond querying, such as deployment and staging environments, version management, or tooling for AI agents.

## What Is the Same Everywhere, and What Each Operator Sets

| The same with every Gateway Operator | Set by each Gateway Operator |
| :-- | :-- |
| Subgraph code, the manifest, and the [Graph CLI](/subgraphs/developing/creating/install-the-cli/) | API keys and authentication |
| [Publishing](/subgraphs/developing/deploying-publishing/publishing-a-subgraph/) to The Graph Network, which happens onchain | Billing, pricing, and payment methods |
| [Curation signal](/subgraphs/developing/curating/) | Rate limits and key restrictions |
| [Subgraph IDs and Deployment IDs](/subgraphs/querying/subgraph-id-vs-deployment-id/) | Staging and development environments |
| The [GraphQL API](/subgraphs/querying/graphql-api/) | Support channels and terms of service |

## What to Compare

- **Networks:** whether the operator serves the networks your Subgraphs index.
- **Payment methods:** GRT, credit card, or other methods.
- **Pricing:** the pricing model and any free allowance. Check each operator's live pricing page for current rates.
- **Authentication and key controls:** restricting a key to domains or Subgraphs, and setting spending limits.
- **Staging:** whether the operator offers a development endpoint before you publish.
- **Additional services:** tools beyond querying that you might need.
- **Support:** support channels, response times, and a public status page.
- **Indexer transparency:** whether the operator publishes how it selects, measures, and blocks Indexers.

## Switching Gateway Operators

To query through a different Gateway Operator:

1. Create an account and an API key with the new operator.
2. Change your query endpoint to the new operator's endpoint, using the same Subgraph ID or Deployment ID.
3. Run both endpoints side by side until you are confident, then retire the old key.

You do not need to republish your Subgraph or change its code. API keys work only with the operator that issued them. For example, API keys from Subgraph Studio authenticate only on The Graph Foundation's Gateway.

## The Graph Foundation's Gateway

The Graph Foundation operates a gateway at `gateway.thegraph.com`, together with [Subgraph Studio](/subgraphs/providers/subgraph-studio/overview/) and [Graph Explorer](https://thegraph.com/explorer) at thegraph.com. The Foundation's Gateway is the default throughout these docs.

- **API keys:** create them in Subgraph Studio. See [Managing API Keys](/subgraphs/providers/subgraph-studio/managing-api-keys/).
- **Billing:** pay with GRT or credit card in Subgraph Studio. See [Billing](/subgraphs/providers/subgraph-studio/billing/).

Subgraph Studio also works for developers who query through other Gateway Operators. You can create, deploy, version, and publish Subgraphs in Studio without querying through the Foundation's Gateway.

## Endorsed Gateway Operators

These Gateway Operators are independent teams that meet The Graph Foundation's published [Endorsement criteria](/gateways/subgraphs/ecosystem/working-with-the-foundation/#endorsement). Each one sets its own pricing, terms, and support. Endorsement means that an operator meets those criteria. It does not mean that The Graph Foundation operates or guarantees its service.

## Run Your Own Gateway

Anyone can run a gateway on The Graph Network, without permission from The Graph Foundation. See the [Subgraph Gateway docs](/gateways/subgraphs/overview/) and [Working with The Graph Foundation](/gateways/subgraphs/ecosystem/working-with-the-foundation/).
