## 1. What is Subgraph Studio?

[Subgraph Studio](https://thegraph.com/studio/) is a web app, operated by The Graph Foundation, for creating, managing, and publishing Subgraphs. It also issues API keys for The Graph Foundation's Gateway. Any developer can use it to publish, whichever gateway they query through.

## 2. How do I create an API Key?

To create an API, navigate to Subgraph Studio and connect your wallet. You will be able to click the API keys tab at the top. There, you will be able to create an API key.

Subgraph Studio API keys authenticate queries to The Graph Foundation's Gateway only. If you query through another Gateway Operator, get a key from that operator. See [Subgraph Providers](/subgraphs/providers/overview/).

## 3. Can I create multiple API Keys?

Yes! You can create multiple API Keys to use in different projects. Check out the link [here](https://thegraph.com/studio/apikeys/).

## 4. How do I restrict a domain for an API Key?

After creating an API Key, in the Security section, you can define the domains that can query a specific API Key.

## 5. Can I transfer my Subgraph to another owner?

Yes, Subgraphs that have been published to Arbitrum One can be transferred to a new wallet or a Multisig. You can do so by clicking the three dots next to the 'Publish' button on the Subgraph's details page and selecting 'Transfer ownership'.

Note that you will no longer be able to see or edit the Subgraph in Studio once it has been transferred.

## 6. How do I find query URLs for Subgraphs if I’m not the developer of the Subgraph I want to use?

You can find the query URL of each Subgraph in the Subgraph Details section of Graph Explorer. When you click on the “Query” button, you will be directed to a pane wherein you can view the query URL of the Subgraph you’re interested in. The query URL in Graph Explorer uses The Graph Foundation's Gateway. Replace the `<api_key>` placeholder with an API key from Subgraph Studio. To query through another Gateway Operator, use that operator's endpoint with the same Subgraph ID.

You can query any Subgraph published to the network, not only your own. These queries are billed like any other query.

## 7. How do I get GRT to pay for queries?

You can buy GRT on centralized exchanges like Coinbase and Binance, or swap for it on Uniswap on Arbitrum One. See [Getting GRT](/resources/getting-grt/). To pay with a credit card instead, see [Query Payments with credit card](/subgraphs/providers/subgraph-studio/billing/#query-payments-with-credit-card). These payments cover queries through The Graph Foundation's Gateway.

## 8. Does my GRT need to be on Arbitrum One?

Your billing balance is held on Arbitrum One, and you need ETH on Arbitrum One to pay gas. Subgraph Studio accepts GRT deposits from Arbitrum One or Ethereum Mainnet and bridges Ethereum GRT for you. To move GRT in your own wallet from Ethereum Mainnet to Arbitrum One, see [Bridging GRT](/resources/bridging-grt/).

## 9. Why isn't my published Subgraph being indexed?

Published Subgraphs need curation signal to attract Indexers. See [Curating](/subgraphs/developing/curating/) for how much signal to add on each type of network.

## 10. When does Subgraph Studio archive a Subgraph version?

A Subgraph version in Studio is archived if and only if it meets all of these criteria:

- The version is not published to the network (or pending publish).
- The version was created 45 or more days ago.
- The Subgraph hasn't been queried in 30 days.

In addition, when you deploy a new version of a Subgraph that has not been published, Studio archives the N-2 version.

You can bring back any version that this policy archives.
