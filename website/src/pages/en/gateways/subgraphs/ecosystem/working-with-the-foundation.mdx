Anyone can run a gateway on The Graph Network, without an application or permission from The Graph Foundation. This page is for teams planning or running a gateway. It describes what the Foundation offers every Gateway Operator, how Endorsement works, and the commitments that apply to every gateway.

## The Foundation's Role

The Graph Foundation operates The Graph Foundation's Gateway, together with Subgraph Studio and Graph Explorer. It also operates protocol components that every gateway depends on, such as the Subgraph Service and the Subgraph Availability Oracle. The Foundation is both a steward of the network and a Gateway Operator, and the commitments on this page limit how that affects other Gateway Operators.

## Enablement: What Every Gateway Operator Gets

Every team that wants to run a gateway gets the following, with no application or agreement:

- **Open-source software:** the [gateway](https://github.com/graphprotocol/gateway), [Graph Node](https://github.com/graphprotocol/graph-node), [GraphTally](/gateways/subgraphs/components/graph-tally/), [Titorelli](/gateways/subgraphs/components/titorelli/), and [Gateway in a Box](/gateways/subgraphs/components/gateway-in-a-box/).
- **Documentation:** these Subgraph Gateway docs, including context on [pricing](/gateways/subgraphs/consumer-side/pricing-payments/), common practices, and common errors.
- **Setup help:** limited technical help to get a gateway live, covering configuration, wallets and escrow funding, and the first successful queries.

### What Enablement Does Not Include

- **Support after launch:** once your gateway is live, you own its uptime, incidents, and support for your consumers.
- **Promotion:** Enablement includes no public mention, listing in the docs, marketing, or user referrals.
- **Users or data:** Enablement includes no access to the users or usage data of The Graph Foundation's Gateway.
- **Subgraph Studio API keys:** these work only on The Graph Foundation's Gateway. Issue your own keys to your consumers.

### What the Foundation Does Not Ask For

At Enablement, the Foundation asks for no access to your intellectual property, users, or revenue, and has no say over your pricing, product, or marketing.

## Endorsement

Endorsement is The Graph Foundation's public acknowledgement that a Gateway Operator meets the Foundation's transparency, conduct, and brand criteria. An Endorsed Gateway Operator gets:

- A dedicated page in the Subgraph docs, and a listing on the [Subgraph Providers](/subgraphs/providers/overview/) overview.
- An acknowledgement on The Graph's social and community channels when it launches.

### Transparency Data

Every Endorsed Gateway Operator publishes these five items in a public place, with no credentials required, and keeps them current:

1. **Production changelog:** for each production change, the date, a version label, the areas it affects (such as Indexer selection, eligibility, payments, or reporting), and the minimum indexer-service and graph-node versions that the gateway enforces.
2. **Blocklist:** the Indexers and POIs that the gateway blocks, per deployment.
3. **Per-Indexer QoS data:** for each Indexer and deployment, the attempts the gateway sends, their outcomes, and their latency, for every environment that pays Indexers.
4. **Network names:** IDs from the [networks registry](https://github.com/graphprotocol/networks-registry), or a published mapping to them.
5. **Deployment IDs:** `Qm…` Deployment IDs in all published data.

These items cover only the traffic between the gateway and Indexers, so every Indexer can see how a gateway routes to it, blocks it, and measures it. Data about a gateway's consumers, such as their query volumes or which Subgraphs they query, is not published and is not shared with the Foundation. The Graph Foundation's Gateway publishes its data to the same standard. For one way to publish QoS data, see [Tracking Quality of Service](/gateways/subgraphs/supply-side/tracking-qos/).

### What Endorsement Does Not Mean

- **No guarantee:** Endorsement means a Gateway Operator meets the criteria. It does not mean that The Graph Foundation operates, guarantees, or holds funds for the gateway.
- **No business relationship:** Endorsement gives neither side access to the other's users or accounting.
- **No other placement:** Endorsement includes no listing in Subgraph Studio or Graph Explorer, and no docs placement beyond the provider page and the Providers overview.
- **No change to protocol access:** a gateway without Endorsement has the same access to the protocol and the Subgraph Service as any other.

Endorsement holds while a Gateway Operator keeps meeting the criteria. The Foundation can withdraw it, after notice, if a Gateway Operator stops meeting them.

## Further Collaboration

Further collaboration with The Graph Foundation beyond Endorsement is available by individual agreement.

## Commitments to Every Gateway Operator

- **Same terms:** the Foundation offers the same terms to every Gateway Operator at Enablement and at Endorsement.
- **Same rails:** The Graph Foundation's Gateway runs the same open-source gateway software, Indexer selection, and GraphTally payments described in these docs, with no privileged routing.
- **Neutral protocol components:** the protocol components that the Foundation operates, such as the Subgraph Service and the Subgraph Availability Oracle, treat every gateway the same way, including The Graph Foundation's Gateway.
- **Shared improvements:** improvements to the gateway software go back into the open-source repositories that every Gateway Operator uses.
- **Low switching costs:** published Subgraphs live onchain, so any gateway can serve any of them. A consumer who changes gateways needs only a new endpoint and API key.
- **Disputes:** a Gateway Operator that believes the Foundation has favored its own gateway, or misapplied these terms, can take the dispute to The Graph Council.

## Get in Touch

To ask about setup help or Endorsement, email The Graph Foundation at [info@thegraph.foundation](mailto:info@thegraph.foundation). Setup help is limited and best-effort.
